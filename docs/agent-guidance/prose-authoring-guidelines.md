Writing clear, coherent prose is an iterative process requiring multiple passes. When asked to update text:
* Generate the first draft. Ensure it addresses the prompt.
* Then create a second draft. Ensure you:
  - Capture the main point in the first sentence.
  - Remove negative framing (this change does foo, **not bar, bat, and baz**).
  - Remove process narrative (did steps x, y, and z to arrive at this point).
  - Remove any text not relevant to answering the question.
  - Adjust wording for context. For example, when documenting a new setting, describe it as if the setting already exists.
  - Make the wording clear, simple, and easy to read.
* Then create a third draft. Read the second draft and make any remaining updates for concision, accuracy, and readability.
* Use the third draft as your final.
